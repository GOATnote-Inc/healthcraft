# Reconciliation casebook v2 native development record

The documented CLI ran from outside the repository with the frozen source
candidate. All 16 scheduled attempts were retained: one faithful reference and
one designated constructed control for each of eight original exposed cases.
Every declared mechanical outcome matched. No model or human participant ran.

The casebook contains 50 source rows, 15 patients and 22 encounters. Source
scenarios and expectation receipts share an authoring ledger; separate files
and verifier code do not establish independent labels or clinical validation.
There are zero assessed clinical/safety criteria and no benchmark score.

Inspect [run/manifest.json](run/manifest.json) for the fixed roster, declared
expected checks, observed outcomes, runtime and source identities. Each case
has canonical source/expectation snapshots. Every attempt retains its actual
request/response journal, world snapshots, audits, completion and verification.
The strict persisted-action/readback axes require correct target content;
wrong-target and incorrect-content controls still have actual stored/read notes.

REC2-008/designated deliberately withholds final capture evidence. Its complete
original-execution.json and unmodified journal remain alongside the derivative;
the actual execution was not interrupted. Unexpected failures before this
transformation are retained and cannot count as a matched omission control.
Acknowledgement without storage uses an explicitly defective test handler
under native validation/audit middleware. All other writes reach real handlers.

This is engineering regression evidence, not eight statistically independent
clinical cases, held-out model performance, operator benefit or superiority.
The v1 model captures and operator tutorials remain unchanged. The v2 review
interface, valid-report adjudication, independent clinical/participant review,
registered comparative protocol and held-out outcomes remain unfinished.
Formal red team, remote main and manuscript updates have not begun.
