# Offline operator review tutorial

Open [the assisted packet](assisted/report.html) or
[the raw-evidence packet](raw/report.html). Both contain the same four existing
MedGemma/Nemotron attempts and six blank questions per attempt. All four attempts
share one exposed synthetic scenario family. No fresh models, cases or
participants were added; these are examples, not comparison-study observations.

The assisted display adds the recomputed explanation. Both expose scenario,
evidence, expectations and oracle data, and use the same citation/response
format. Downloaded responses require later import and independent adjudication.
The example reviewer alias denotes no person. Replace the example assignment
with your own newly built packet to collect a response.

Original source bytes and all oracle verdicts are unchanged. Controlled reports
are regenerated from verified JSON; captured source HTML is not executed.
Automated checks establish parsing, binding and export contracts, not visual
usability. Browser QA, participant testing and clinical validation remain
unperformed. These files are neither a superiority result nor the gated formal
red team. Remote main and the manuscript remain unchanged.
